One line, 117 characters: the funniest one-line excuse a robot vacuum
can give for missing a spot — delivered in flat, deadpan robot voice,
as a hilariously bureaucratic reclassification.

> That spot was not missed. Per Section 4 of my cleaning mandate, it has been reclassified as a protected dust habitat.

## Run

```sh
python3 main.py            # writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is stdlib-only and deterministic: it writes exactly the one
line above to `entry.txt`, and `validate()` enforces the competition
rules (single line, 1–200 characters, non-whitespace).
